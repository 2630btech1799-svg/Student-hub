# StudentHub — Student Dashboard Website

A polished, responsive beginner project made with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open the `StudentHub_Website` folder in VS Code (or any editor).
3. Open `index.html` in a browser. You can also use the VS Code Live Server extension.
4. No build step, backend, database or framework is required.

## Website features
- Responsive sidebar navigation
- Dashboard overview with stats and course progress
- Course listing
- Assignment manager: add, complete, delete and filter tasks
- Tasks persist in browser localStorage
- Weekly timetable
- Academic results page
- Mobile menu for smaller screens

## Project files
- `index.html` — website structure and page content
- `style.css` — visual design and responsive layout
- `script.js` — navigation, course rendering and assignment functionality

## Make it your own
Update the student name, sample course details, timetable and grades in `index.html` and `script.js`.
The attendance, grades, timetable and course progress are demo values. Assignment data is saved only in the browser where you use the website.
